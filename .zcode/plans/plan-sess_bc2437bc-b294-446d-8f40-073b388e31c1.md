# خطة مشروع: موقع محامي — Laravel + Filament داشبورد + لاندنج Blade جاهزة للتصميم

## 1) تهيئة المشروع
- `composer create-project laravel/laravel` في `/Users/abdelwahab/Core/Lawer` (أحدث Laravel مستقر — PHP 8.5 متوافق)
- تثبيت **Filament 4** (لوحة التحكم) + **spatie/laravel-translatable** (محتوى بلغتين في نفس السجل)
- قاعدة بيانات **MySQL** جديدة `lawyer_landing` (السيرفر شغال محليًا)
- Tailwind v4 + Vite + Alpine (التفاعلات البسيطة زي الموبايل منيو والـ FAQ)
- `git init` + commit أولي بعد كل مرحلة رئيسية

## 2) اللغات و RTL (من الأول زي ما طلبت)
- العربي افتراضي على `/ar` والإنجليزي على `/en`، و `/` بيعمل redirect لـ `/ar`
- Locale middleware + ملفات ترجمة `lang/ar` و `lang/en` لواجهة الموقع
- `<html lang="ar" dir="rtl">` ديناميكي حسب اللغة، خط Cairo (عربي) و Inter (إنجليزي)
- **داشبورد Filament نفسه عربي RTL** على `/admin`

## 3) قاعدة البيانات (هيكل موقع محامي قياسي — جاهز نمدده لما الـ reference يوصل)
- **Setting** (صف واحد): اسم المحامي/المكتب باللغتين، نبذة، موبايل/واتساب/إيميل/عنوان، سوشيال، إحصائيات (سنين خبرة، عدد قضايا...)، صور (لوجو/hero)، إعدادات SEO لكل لغة + OG image
- **PracticeArea** مجالات الممارسة (اسم ووصف باللغتين، أيقونة، ترتيب، تفعيل)
- **Testimonial** آراء العملاء (باللغتين + تقييم نجوم)
- **Faq** أسئلة شائعة (باللغتين)
- **Article** مقالات باللغتين (slug، صورة غلاف، نشر/مسودة، تاريخ)
- **ContactMessage** رسائل فورم الاستشارة (اسم، موبايل، رسالة، مقروء/جديد)
- **Seeders** بمحتوى واقعي باللغتين — الداشبورد يبان مليان وشغال فورًا

## 4) داشبورد Filament (`/admin`)
- تسجيل دخول مستخدم واحد (يتزرع: admin@lawyer.test + باسورد قوي) 
- Resource لكل موديل: جدول + فورم إنشاء/تعديل باللغتين (تبويب AR/EN)
- صفحة **إعدادات** موحدة بتابات: بيانات المكتب / التواصل والسوشيال / الإحصائيات / SEO
- رفع صور للوجو والـ hero وأغلفة المقالات و OG image
- **صندوق الرسائل**: الرسائل الجديدة أولًا + تحديد مقروء + عرض التفاصيل
- الصفحة الرئيسية للداشبورد: عدادات سريعة (رسائل جديدة، مقالات، مجالات...)

## 5) بنية اللاندنج الجاهزة للتصميم
- صفحة Blade مؤقتة نظيفة بتعرض كل الداتا الحقيقية من الداشبورد باللغتين (placeholder يتشال أول ما التصميم يوصل)
- الـ sections متقسمة components/partials جاهزة، فتنفيذ تصميمك بعدين = نحط الـ classes والتنسيقات على نفس الداتا
- صفحة المدونة + صفحة المقال باللغتين (جاهزين للـ SEO من دلوقتي)
- **فورم التواصل شغال فعلًا**: validation + تخزين في الداشبورد + rate limiting

## 6) SEO من الأول
- partial للـ meta يتحكم فيه من الداشبورد: title/description لكل لغة، canonical، **hreflang** (ar/en/x-default)، Open Graph، Twitter Card
- **JSON-LD schema**: Attorney/LegalService على الرئيسية، Article على المقالات، FAQPage على الأسئلة
- **sitemap.xml** ديناميكي (الرئيسية + المدونة + كل مقال باللغتين) + robots.txt
- إعدادات SEO كاملة من الداشبورد (بما فيها Google verification code)

## 7) التسليم والاختبار
- تشغيل السيرفر محليًا واختبار بالبراوزر: العربي RTL والإنجليزي، الداشبورد CRUD كامل، فورم التواصل، الـ meta tags والـ sitemap
- **README** بالعربي: طريقة التشغيل + بيانات دخول الداشبورد + شرح سريع لكل part
